# Portfolio

Personal portfolio of Hady Gustianto. It's a static site built with Astro, Tailwind CSS and MDX.

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # type check + production build + internal link check
npm run preview   # serve the production build
```

- [docs/DEPLOY.md](docs/DEPLOY.md): deploying to Vercel with a custom domain
- [docs/TESTING.md](docs/TESTING.md): what was verified and how
- [DESIGN.md](DESIGN.md): the design system (Kraft & Ink)
