## Overview

A LinkedIn-inspired social network built as two repositories:

- a Go GraphQL API using gqlgen, chi and GORM on PostgreSQL;
- a React + TypeScript frontend built with Vite and SCSS, with Firebase for media storage.

## Features

- **Accounts:** registration, login with JWT, email activation and password reset.
- **Profiles:** education, experience and profile details.
- **Social graph:** connection requests, connections and follows.
- **Feed:** posts, comments, likes and hashtags.
- **Real-time messaging and notifications** over WebSockets.
- **Job board:** post and browse job listings.
