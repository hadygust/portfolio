## Overview

Karana OS is a hospitality platform for businesses that run several properties. As a freelancer, I own its pricing and revenue module end to end: the data model, the computation engine and the UI.

## What I did

- **Led a major architecture redesign.** I restructured the module around 5 core tables and migrated the database to the new design.
- **Wrote the pricing computation engine** in TypeScript, running on Supabase Edge Functions on top of Supabase PostgreSQL.
- **Built the UI** in Next.js and TypeScript.

## How I work on it

I build every feature with Claude Code. I generate code from specs, then run multi-agent review and testing workflows. Nothing ships until it passes automated reviews and tests.

This kept turnaround fast. I handled client feedback the same day it came in, for 58+ revisions across 5 review cycles in 6 weeks.
